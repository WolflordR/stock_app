# 個股近四季財報與本益比

個股詳頁的「近四季財報與本益比變化」使用 `financial_eps.db` 的歷史表，並透過 `GET /api/stocks/{stock_id}/financial-trends` 提供資料。

- 財報：公開資訊觀測站 `ajax_t163sb04` 上市／上櫃歷史綜合損益表，依年度與季別匯入 `stock_income_quarterly`。原表是年初累計；單季 EPS、營收和毛利由同年度前一季累計數相減。缺前一季時顯示空值。毛利率為單季毛利除以單季營收；不適用的金融業顯示空值。
- 本益比：上市採證交所投資資訊中心的逐月個股本益比；上櫃採櫃買中心季末交易日個股本益比。兩者都是官方公告值，不以價格除以當季 EPS 自行估算。零、空白及來源不提供的數值維持空值。
- 資料時點：財報年度／季度是統計期間，不代表實際公告時間。匯入表保存首次觀測時間和來源網址。本益比另存資料日期、檢查時間和來源。

`python -m scripts.backfill_financial_trends --quarters 7` 可回補最近七季的上市、上櫃資料。成功的舊季度略過，最近兩季每天重查，以收錄陸續申報及更正的公司。日常 worker 執行 `refresh_financial_history(max_requests=4)`，逐日補齊未完成的季度。個股本益比在第一次打開個股時抓取並快取一天；來源失敗時保留既有歷史，不影響基本資料或 K 線。

2026-10-11 首次本機回補：14 個季度市場請求，12 個成功，匯入 11,798 筆公司季報；2026 Q3 兩個市場的彙總查詢尚無可解析報表，會繼續重試。台積電 2330、環球晶 6488 的最近四季單季 EPS、毛利率及本益比已透過 API 核對。沒有將本機更新部署到 NAS。
