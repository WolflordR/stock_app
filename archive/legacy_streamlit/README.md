# Legacy Streamlit Archive

This folder keeps the old Streamlit UI code for reference only.

The active application is now:

- `apps/web`: React + TypeScript frontend
- `apps/api`: FastAPI backend
- `apps/worker`: data update and import commands
- `modules/core`, `modules/data_sources`, `modules/backtest`: shared backend logic

Do not deploy the files in this archive as the production site.
